# Task Management Board – Phase 2

A frontend-only Kanban board application built as part of an internship project (Phase 2), extending Phase 1 with enhanced interactivity and improved user experience.

---

## 🚀 Features

- Three-column Kanban board: **To Do**, **In Progress**, **Done**
- Create new tasks in any column
- Edit task details:
  - Title
  - Description
  - Priority
  - Due date
- Drag and drop tasks between columns
- Visual status indicators for each column
- Completed task indicator (✓) in Done column
- Delete tasks with confirmation
- Clean, responsive, and intuitive UI

---

## 🛠 Tech Stack

- React (Vite)
- JavaScript (ES6)
- HTML5
- Tailwind CSS
- Git & GitHub
- Vercel (Deployment)

---

## 📌 Project Scope

- Frontend-only application
- No backend or database
- No authentication
- Focus on state-driven UI and user experience
